# Asset Allocator

手机端资产配置工具，已用模块方式合并 `mobile-essential-motion-performance-8` 饼状图版本。

## 饼状图功能

- 点击资产区右上角的饼图按钮，可在卡片/表格视图与饼状图视图之间切换。
- 初始页面、资金与汇率区、汇总、公式和底部操作区均保留原源文件内容；切换时只替换“资产”内容。
- 点击任一资产板块会以最短路径将其旋转到饼图正下方、显示对应详情，并触发向上抬起的一体式 3D 厚度效果。
- 板块间始终保留间隙，点击和超配状态下会进行流体吸附与排斥重排。
- 当前正式版本使用圆润连续轮廓，VOO 使用单段有机内曲线。
- 手机端保留完整的“资产卡片收拢 → 中心聚合 → 连续变形成饼块”转换；末段通过轮廓插值和交叉淡化完成身份交接，返回卡片时反向执行。
- 手机端即使系统开启“减弱动态效果”，仍保留这段用于表达视图关系的必要转换，不再直接跳帧切换。
- 转换仅动画轻量代理的合成器属性，选中动画缓存 SVG 节点，在保留流体吸附与 3D 抬升的同时控制掉帧。
- 手机端转换轮廓降低为 18 个平滑采样点；旋转保持逐帧更新，较昂贵的 SVG 轮廓写入单独限频，避免拖慢整盘旋转。
- 手机端会在首屏空闲时预先生成隐藏饼图并缓存变形轮廓；不支持 `requestIdleCallback` 的 iOS Safari 也会自动预热，首次点击不再现场测量全部 SVG 路径。
- 资产清零后，剩余 3 个或 4 个资产会分别自然重排成等角三叶/四叶布局；数值不被强制等分，板块间始终保留间隙。
- VOO 大比例选中状态使用加宽的有机内缘连接，避免中心位置形成尖嘴。

## 手机触摸边界

- 非编辑文字在手机端禁止长按拖选，避免滑动时误触整页选择。
- 输入框、文本域和可编辑区域仍保留文字编辑与选择能力。
- 在饼状图正面开始的拖动由旋转手势独占，不会带动页面上下滚动。
- 饼状图之外以及资产详情区域仍保留正常的纵向页面滑动。

## 部署

将本目录内全部文件和文件夹上传到 GitHub 仓库根目录即可。GitHub Pages 需要从该目录的 `index.html` 发布。

首次部署或覆盖旧版本后，Service Worker 会升级到新缓存；若手机桌面 PWA 仍显示旧界面，完全关闭后重新打开一次。
